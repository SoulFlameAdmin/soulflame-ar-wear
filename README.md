# SoulFlame AR Wear

Самостоятелен прототип за виртуално пробване на дрехи, който по-късно ще бъде свързан към Twins.

## v0.1

- 3D преглед на базова тениска
- управление с пръст/мишка
- размери XS, S, M, L, XL, XXL
- параметри на тялото
- автоматична препоръка за размер
- оценка за прилягане
- качване на собствен GLB/GLTF модел
- мобилен интерфейс

## Следваща версия

- камера
- MediaPipe body tracking
- поставяне върху тялото
- профили на материи
- връзка към SoulFlame Twins

## Публикуване

Проектът е статичен и може да се публикува директно във Vercel без build command.
